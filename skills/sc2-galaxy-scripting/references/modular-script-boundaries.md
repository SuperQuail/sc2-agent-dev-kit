# 模块化脚本边界规则

1. **顶层声明：** 每个被 include 的 `.galaxy` 文件必须从花括号深度 0 的声明开始，并以闭合的函数花括号 `}` 结束。把函数体拆到文件边界之外会产生编译错误。
2. **禁止重复函数：** 在多个被 include 的脚本里定义同名函数会以 `"function already defined: <name>"` 失败。
3. **前向引用：** 在脚本块内，函数必须 **先定义后调用**。GUI 触发器调用独立链接，但脚本到脚本的调用要求被调用者在编译顺序中出现在前面。

不要把函数体拆到多个文件；不要重复定义同名函数。安排项目脚本顺序，使被调用者在脚本块内出现在调用者之前（GUI 触发器调用独立链接）。
