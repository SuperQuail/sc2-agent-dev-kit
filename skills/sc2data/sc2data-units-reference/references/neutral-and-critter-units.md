# 中立单位与野生动物

写地图脚本时用到的资源、塔与可破坏物的编辑器 ID。

## 常用中立/野生动物单位

| 显示名 | 编辑器 ID | 备注 |
|---|---|---|
| Mineral Field (small) | `MineralField450` | 450 晶体矿的矿簇 |
| Mineral Field (large) | `MineralField750` | 750 晶体矿的矿簇 |
| Vespene Geyser | `VespeneGeyser` | 放置精炼厂之前的原始瓦斯泉 |
| Xel'Naga Tower | `XelNagaTower` | 视野塔，单位站上去即激活 |
| Destructible Rock | `DestructibleRock6x6` | 常用阻挡岩石（有多种尺寸变体） |
