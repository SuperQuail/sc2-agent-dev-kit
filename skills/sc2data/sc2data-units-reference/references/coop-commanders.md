# 合作任务指挥官

全部 18 位合作任务指挥官，含英雄单位 ID、打法风格与标志性单位。

> **提示：** 上文战役表中带 "Co-op" 标记的合作单位 ID 属于此处列出的指挥官，按 Commander 列对应。
