# 战役与合作单位

编辑器中仍然存在、可作为 parent 或 `UnitCreate` 目标的战役专属人类、虫族与星灵单位。

## 战役与合作单位

这些单位存在于编辑器数据中（可作为 parent 或 `UnitCreate` 目标），但不在标准多人对战里。多数来自单人战役或合作任务指挥官。编辑器 ID 为尽力整理——确切目录 ID 一律到 [ShadowDragon Base.SC2Data](https://github.com/ShadowDragonSC2/Base.SC2Data/blob/main/GameData/UnitData.xml) 核实。

> **战役缩写：** WoL = 自由之翼，HotS = 虫群之心，LotV = 虚空之遗，NCO = 诺娃隐秘行动（合作），Co-op = 合作任务指挥官单位
