# 写作指引与术语

- 如果任务是对既有文本做翻译，保留源含义、占位符、标记与语气。
- 如果任务需要全新的本地化文本（不是翻译既有字符串），先向用户要模板或参考示例——语气与措辞是项目专属的。
- 好模板的来源：同一地图/模组里的既有键、指定的阵营口吻、UI 措辞示例、提示框套路，或可比的 `GameStrings.txt` 样例。
- 没有模板时，声明该文本是尽力草稿，并保持措辞中性、简短、SC2 风格。
- 在 `GameStrings.txt`、`ObjectStrings.txt` 与面向 UI 的字符串之间保持术语一致。批量翻译走同级的本地化工作流，连同它的项目上下文与审阅要求。
